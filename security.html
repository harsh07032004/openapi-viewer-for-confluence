Security

Architecture

  • Built only on Atlassian Forge and eligible for Runs on Atlassian. Code runs on Atlassian infrastructure; specs are stored in Forge storage for your site.
  • No external network access is declared, so the app cannot send data off Atlassian. No remote REST APIs, no third-party sub-processors.
  • All Confluence API calls run as the current user, so page restrictions are enforced by Confluence on every read and save.
  • No personal data, passwords, API tokens or other secrets are collected or stored.

Development practices

  • Automated tests run on every change; dependencies are monitored and updated automatically.
  • Vulnerabilities are fixed within Atlassian's Marketplace security bug-fix timeframes (critical 10 days, high 4 weeks, medium 12 weeks, low 25 weeks).

Reporting a vulnerability

Report privately through Atlassian's Marketplace security process, or open a minimal issue at https://github.com/harsh07032004/openapi-viewer-for-confluence/issues asking for a private contact. Do not post exploit details publicly.
