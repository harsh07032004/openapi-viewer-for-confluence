Moving off a Connect-based Swagger or OpenAPI macro

Atlassian Connect reaches end of support at the end of 2026, and Connect apps could no longer ship normal updates after 31 March 2026. If your Swagger or OpenAPI macro is a Connect app, it will stop receiving security fixes.

1. Check whether your current macro is a Connect app

As a Confluence admin, open Settings → Apps → Manage apps, find the macro's app and open its Marketplace listing. Apps with the Runs on Atlassian badge are Forge apps.

2. Move each page (about two minutes)

  1. Install OpenAPI & Swagger Viewer for Confluence from the Atlassian Marketplace.
  2. Open a page that uses the old macro and click Edit.
  3. Copy the spec text from the old macro's settings, or get the spec file from your repository.
  4. Type /OpenAPI Viewer, paste or upload the spec, click Save.
  5. Delete the old macro and publish.

To find every page that uses the old macro, search Confluence with CQL: macro = "old-macro-key". The key appears in the page's storage format.

Differences to expect

  • Try it out is off, so no requests leave Confluence.
  • Specs are pasted or uploaded instead of fetched from a URL. Git sync is on the roadmap; tell us if you need it at https://github.com/harsh07032004/openapi-viewer-for-confluence/issues.
